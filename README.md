# Тайный Санта — закрытый Telegram-бот

Приватный Telegram-бот на TypeScript (`grammY`) для проведения «Тайного Санты» в небольшой компании друзей.

## Возможности
- **Закрытый доступ:** вход только по пригласительной ссылке `?start=<код>` от организатора (случайные люди не попадут в игру).
- **Анкета и вишлист:** имя, пожелания, анти-вишлист / удобный ПВЗ. При обновлении вишлиста после жеребьёвки Санта получает уведомление.
- **Пары-исключения:** в админ-панели можно задавать и удалять запрещённые пары (взаимные `↔` и односторонние `→`), чтобы близкие люди не выпадали друг другу.
- **Жеребьёвка без спойлеров:** организатор видит только общий прогресс (кто заполнил вишлист, кто отметил готовность подарка), но не видит, кто кому выпал.
- **Анонимный чат:** переписка Санта ↔ Подопечный через бота с кнопками быстрого ответа.
- **Управление парами и участниками:** удаление участников, удаление пар-исключений и полный сброс жеребьёвки с подтверждением.
- **Двойной режим работы:**
  - Локально / без `WEBHOOK_URL` — **Long Polling** + локальная **SQLite** (`./data/santa.db`).
  - На Render (`RENDER_EXTERNAL_URL` или `WEBHOOK_URL`) — **Webhook** + `/health` и `/api/health`.
  - Если в `DATABASE_URL` указан `postgresql://...`, бот автоматически использует **PostgreSQL** в отдельной схеме `secret_santa` (`secret_santa.santa_*`), поэтому он не мешает другим проектам в той же БД. Позже все данные бота можно удалить одной командой `DROP SCHEMA secret_santa CASCADE;`. Иначе используется локальный файл SQLite.

## Настройка на Render (после пуша)
1. В панели Render для этого сервиса добавьте переменные окружения:
   - `BOT_TOKEN` — токен бота от `@BotFather`
   - `ADMIN_TELEGRAM_ID` — ваш числовой Telegram ID (можно узнать у `@userinfobot`)
   - `DATABASE_URL` — оставьте строку подключения к PostgreSQL, если хотите, чтобы данные переживали редеплой и рестарты контейнера. Если удалить `DATABASE_URL`, бот будет использовать локальный SQLite (`./data/santa.db`), но на бесплатном Render диск сбрасывается при каждом перезапуске/деплое.
2. Также убедитесь, что в Render (Settings → Build & Deploy):
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/health`

## Локальный запуск
```bash
cp .env.example .env
# заполните BOT_TOKEN и ADMIN_TELEGRAM_ID
npm install
npm run dev
```
